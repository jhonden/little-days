## 1. 需求背景

LittleDays 是一个温馨的生活记录 App，用于记录穿衣搭配、种花养草、日常手账等生活点滴。

当前项目框架已搭建完成，具备基本的 TabView 结构和 AI 服务抽象层。现在需要设计完整的应用界面框架，为后续功能开发提供统一的设计规范和交互标准。

### 1.1 目标用户

- 主要用户：30岁左右的女性，乐观开朗，热爱生活，喜欢养花
- 使用场景：日常生活记录、穿搭管理
- 设备环境：iPhone（iOS 17.0+）

### 1.2 产品定位

"小日子" - 记录生活中的小美好
- 温馨、治愈、有温度的 App
- 充满阳光森林气息的视觉风格
- 简单易用，不复杂的功能

## 3. 核心设计思路

### 3.1 设计风格定位

**"阳光森林"风格：**
- 🌲 森林感：温暖的绿色，像透过树叶洒下的阳光
- ☀️ 阳光感：暖橙色、淡黄色，光斑效果
- 🍃 自然感：柔和、不刺眼、有机的过渡
- 💚 温馨感：温暖、舒适、治愈

### 3.2 导航结构设计

采用 **TabView + 左侧设置面板** 的结构：

```
┌────────────────────────────────────────────┐
│  ☰  ☀️ LittleDays                        │  ← 导航栏（渐变背景）
├────┬──────────────────────────────────────┤
│    │                                      │
│ 设 │         主内容区域                     │
│ 置 │         (可横向滚动)                   │
│ 面 │                                      │
│ 板 │                                      │
│ (30%│                                      │
│ 宽 │                                      │
│ 度)│                                      │
└────┼──────────────────────────────────────┤
│    │  📱 衣橱  🌱 花园  📔 手账           │  ← TabBar（底部固定）
└────┴──────────────────────────────────────┘
```

### 3.3 交互设计原则

1. **左侧设置面板**：
   - 默认收缩状态
   - 点击左上角 ☰ 按钮展开
   - 面板从左侧滑出，主内容区向右挤压
   - 点击左侧 ☰ 按钮收起（或在面板外区域收起）

2. **TabBar 交互**：
   - 底部固定
   - 点击切换 Tab
   - 选中状态用橙色高亮

3. **流畅动画**：
   - 所有交互带动画效果
   - 使用 spring 动画，自然流畅

## 4. 数据模型设计

### 4.1 主题配置数据模型

```swift
/// 主题类型
enum AppTheme: String, CaseIterable, Codable {
    case followSystem = "跟随系统"
    case light = "浅色模式"
    case dark = "深色模式"
}

/// AI 服务提供商
enum AIProvider: String, CaseIterable, Codable {
    case local = "本地 AI"
    case cloud = "云端 AI"
}

/// App 配置
struct AppConfig: Codable {
    var theme: AppTheme
    var aiProvider: AIProvider
    var enableAutoIdentify: Bool

    static let `default` = AppConfig(
        theme: .followSystem,
        aiProvider: .local,
        enableAutoIdentify: true
    )
}
```

### 4.2 Tab 配置数据模型

```swift
/// Tab 配置
struct TabConfig: Identifiable {
    let id: Int
    let title: String
    let icon: String
    let isEnabled: Bool
}

/// 所有 Tab 定义
enum AppTab: Int, CaseIterable {
    case wardrobe = 0
    case gardening = 1
    case diary = 2

    var config: TabConfig {
        switch self {
        case .wardrobe:
            return TabConfig(id: 0, title: "衣橱", icon: "tshirt.fill", isEnabled: true)
        case .gardening:
            return TabConfig(id: 1, title: "花园", icon: "leaf.fill", isEnabled: false)
        case .diary:
            return TabConfig(id: 2, title: "手账", icon: "book.fill", isEnabled: false)
        }
    }
}
```

## 7. 服务层设计

### 7.1 AppConfigService

负责 App 配置的保存和加载：

```swift
class AppConfigService {
    private let userDefaults = UserDefaults.standard

    // 保存配置
    func saveConfig(_ config: AppConfig) {
        if let data = try? JSONEncoder().encode(config) {
            userDefaults.set(data, forKey: "appConfig")
        }
    }

    // 加载配置
    func loadConfig() -> AppConfig {
        guard let data = userDefaults.data(forKey: "appConfig"),
              let config = try? JSONDecoder().decode(AppConfig.self, from: data) else {
            return AppConfig.default
        }
        return config
    }
}
```

### 7.2 依赖注入

```swift
struct AppConfigKey: EnvironmentKey {
    static let defaultValue = AppConfig.default
}

extension EnvironmentValues {
    var appConfig: AppConfig {
        get { self[AppConfigKey.self] }
        set { self[AppConfigKey.self] = newValue }
    }
}
```

## 9. 风险与注意事项

### 9.1 技术风险

| 风险 | 影响 | 概率 | 应对措施 |
|------|------|------|---------|
| 设置面板动画性能问题 | 中 | 中 | 使用 GeometryReader + 动画优化，避免重绘 |
| 不同屏幕尺寸适配 | 低 | 中 | 测试多种 iPhone 设备（SE、15、15 Pro Max） |
| 暗黑模式适配 | 低 | 高 | 使用系统颜色，确保暗黑模式下正常显示 |

### 9.2 设计风险

| 风险 | 影响 | 概率 | 应对措施 |
|------|------|------|---------|
| 配色方案不满足预期 | 中 | 低 | 先实现基础框架，快速迭代调整配色 |
| 交互方式不够直观 | 中 | 中 | 添加引导提示，优化交互反馈 |

### 9.3 实施注意事项

1. **动画优化**
   - 使用 `withAnimation(.spring())` 而非 `withAnimation(.linear)`
   - 避免在动画过程中重绘整个视图
   - 使用 `GeometryReader` 获取准确尺寸

2. **适配性**
   - 在不同 iPhone 设备上测试
   - 注意刘海屏的安全区域
   - 确保 TabBar 不被 Home Indicator 遮挡

3. **代码规范**
   - 遵循 MVVM 架构
   - 遵循 SwiftUI 最佳实践
   - 代码注释使用中文
